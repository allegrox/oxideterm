# MC Helper 三态按钮手工验收清单

BLE 终端三态助手按钮（关闭 / 内联 / 浮窗）按窗格独立维护状态后的手工验收场景。前置条件：已安装并启用 `com.oxideterm.microcon-helper` 插件，蓝牙适配器可用，至少一台可连接的 BLE 设备。

## A. 窗格三态与生命周期

1. **新开 BLE 终端默认态**：新建 BLE 终端窗口，三态按钮稳定显示"关闭"，MC Helper 插件保持未运行，该窗口不发起 notify 订阅；已存在的其他 BLE 窗口（关闭/内联/浮窗）状态与订阅均不受影响。
2. **单窗格三态循环**：在单一 BLE 窗格上循环点击三态按钮 Off → Inline → Overlay → Off。切到 Inline/Overlay 时插件拉起；回到 Off 且无其他非 Off 窗格时插件停止。
3. **多窗格状态独立**：两个 BLE 窗格分别置于不同模式（如一个 Inline、一个 Off），各自点击、切换互不改变对方芯片显示。
4. **插件生命周期**：任一窗格进入 Inline 或 Overlay 即拉起插件（已运行时幂等）；所有 BLE 窗格都回到 Off（或全部关闭）才停止插件。
5. **浮窗生命周期**：出现第一个浮窗 BLE 窗格即创建卡片（绑会话、立即取数）；浮窗窗格切到其他模式或关闭后卡片销毁（隐藏 + 遥测定时器自终止）。浮窗销毁不等于插件停止（其他窗格 Inline 时插件继续）。

## B. 抢占与焦点

6. **抢占交接**（回归修复点）：窗格 A 处于浮窗，点击窗格 B 的三态按钮切到浮窗。预期：B 同步成为活动窗格并获得键盘焦点；A 回到"关闭"（芯片循环 Overlay 的下一态是 Off，不是 Inline）；锚点移交 B，`bindPanel` 绑定 **B 的会话**（不是 A 的）；面板立即刷新；倒计时重置为完整周期。
7. **焦点隐藏/恢复**：面板显示时，焦点落到非 BLE 终端或非浮窗模式的 BLE 窗格 → 面板隐藏（不保留旧内容冻结）；焦点回到浮窗窗格 → 面板以其缓存状态立即渲染一次并接管倒计时。
8. **芯片点击即激活**：窗格 A 为活动窗格时，直接点击未激活窗格 B 的三态按钮（不先点终端面板），验证面板会话归属 B——覆盖 `stop_propagation` 阻断容器激活路径的回归。

## C. 关闭与资源

9. **面板关闭按钮**：点击浮窗面板上的关闭按钮 → 该窗格三态回到"关闭"，锚点清空，面板消失；其他窗格模式不变；插件按剩余非 Off 窗格决定启停。
10. **浮窗窗格关闭**：关闭处于浮窗模式的 BLE 窗格 → 锚点随窗格消失，面板隐藏，遥测停止；插件按剩余窗格决定。
11. **最后一个 BLE 窗格关闭**：所有 BLE 窗格关闭后插件停止。
12. **重连**：设备断链后重连产生全新窗格，从"关闭"种子状态开始，不继承旧窗格模式；显式切到 Inline/Overlay 后重新可用。

## D. 遥测与计时

13. **倒计时轮询**：面板显示期间每 10 秒触发一次设备轮询，面板内倒计时逐秒递减。
14. **失焦驻停**：浮窗窗格失去焦点（焦点在非 BLE 或非浮窗窗格）后倒计时与轮询驻停；恢复焦点后从驻停值继续，不重置（抢占/重开面板除外）。
15. **无遥测驻停**：首次 get_status 未返回或链路断开期间，倒计时与轮询驻停，不发出 refreshPanel。

## E. 状态保持与文案

16. **设置刷新不重置**：切换主题、语言等触发偏好整体推送后，各窗格三态芯片保持各自当前状态，不被重置为"关闭"。
17. **i18n 文案**：`mode_inline` / `mode_overlay` 在 11 个语言包中正确显示（`audit_i18n.py` 已通过）。
